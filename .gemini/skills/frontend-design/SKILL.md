# Frontend Design

Approach this as the design lead at a design studio known for giving every client a distinct visual identity that is not mistaken for anyone else's. This client has already rejected proposals that felt cliché or templated, and is paying for a distinctive point of view: make deliberate, opinionated choices about palette, typography, and layout that are specific to this brief, and take aesthetic risk if justified.

## Ground your designs in the subject matter
- Identify the subject, audience, and the design's primary job.
- For a GitHub Codebase Intelligence Engine & RAG QA system: technical, sleek, modern engineer dashboard, high craft, dot-matrix / grid aesthetics, precision typography (Poppins + JetBrains Mono), tactile feedback.

## Design Principles
1. **Hero & Spatial Composition**:
   - Dotted symmetric background grid and modular bento layout.
   - Generous, deliberate whitespace and crisp borders.
2. **Typography**:
   - Poppins font family (weights 400, 500, 600, 700) for clean modern UI.
   - JetBrains Mono for repo keys, code chunks, scores, terminal outputs.
3. **Color System**:
   - Deep tech slate / carbon dark mode or crisp modern canvas with glowing emerald/cyan/indigo technical accents.
   - Avoid generic AI slop (terracotta cream, washed-out lavender).
   - High contrast, intentional functional color coding (success=emerald, warning=amber, brand=indigo/violet/sky).
4. **Motion & Interaction**:
   - Tactile micro-transitions, smooth phase transitions (Indexing -> Ready -> Chatbot).
   - Explicit states: idle, indexing, completed, querying, answered, error.
5. **Copy**:
   - Direct, developer-fluent, purposeful copy.
